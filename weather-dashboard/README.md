# Weather Dashboard (Ethereal)

This is a lightweight weather dashboard built with React + TypeScript + Vite + Tailwind.

Setup
1. cd weather-dashboard
2. npm install
3. copy .env.example to .env and set VITE_OPENWEATHER_KEY
4. npm run dev

Notes
- The project uses OpenWeatherMap One Call API. Get an API key from https://openweathermap.org/api
- Do not commit your API key. Use environment vars in Codespaces or your host.
